# Arithmetic with the available tools

Use this skill when the user asks to add, multiply, or compare numbers.

1. Identify the operands and the requested operation. Ask for missing operands.
2. Use `add`, `mul`, or `compare` for the corresponding operation.
3. For a multi-step expression, respect parentheses and operation precedence.
4. Wait for each tool result before using it in another calculation.
5. Report the result with the original units. Do not claim a failed tool call succeeded.
